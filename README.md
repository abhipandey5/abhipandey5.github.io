# Abhishek Kumar Pandey — Portfolio

This repository contains the personal portfolio website for Abhishek Kumar Pandey, a cybersecurity and AI research-focused developer and Ph.D. scholar.

## About

This site serves as a digital profile for my research, academic work, projects, publications, technical interests, and professional milestones. The design follows a cyber-themed, research-oriented aesthetic with a clean, modern interface and interactive components.

## Highlights

- Research-driven portfolio with academic and technical storytelling
- Clean cyber/terminal-inspired visual language
- Responsive layout for desktop, tablet, and mobile devices
- Project and experience sections to showcase research and engineering work
- Interactive UI details including motion, theme styling, and dynamic sections

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Project Structure

- src/components — site sections and reusable UI blocks
- src/data — portfolio data and structured content
- public — static assets and images used across the website
- index.html — base HTML shell and page metadata

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
